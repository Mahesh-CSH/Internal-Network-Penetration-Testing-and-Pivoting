# Low Findings Remediation

## F-12 — Service Version Disclosure

- Minimize service banners.
- Disable unnecessary version information.
- Keep software patched regardless of banner visibility.
- Monitor externally exposed services.

## F-13 — Telnet Exposure

- Disable Telnet.
- Replace Telnet with SSH or another encrypted management protocol.
- Restrict remote administration to trusted hosts.

## F-14 — HTTP Directory Enumeration

- Disable directory listing where unnecessary.
- Remove unused web directories and applications.
- Restrict administrative and documentation directories.
- Remove test applications from production systems.
- Keep web applications and servers updated.
