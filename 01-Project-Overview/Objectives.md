# Assessment Objectives

The objectives of this project were to:

1. Perform reconnaissance against the lab environment.
2. Identify exposed network services.
3. Enumerate service configurations and potential weaknesses.
4. Validate selected vulnerabilities through controlled exploitation.
5. Establish access to the Windows pivot host.
6. Configure routing through the pivot.
7. Demonstrate access to the isolated internal network.
8. Assess the internal Metasploitable 2 system.
9. Document security findings and evidence.
10. Provide remediation recommendations.
11. Perform retesting after remediation.
