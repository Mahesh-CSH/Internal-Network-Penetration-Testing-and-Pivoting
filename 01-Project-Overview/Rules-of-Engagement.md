# Rules of Engagement

## Authorization

All testing was performed against intentionally configured virtual
machines in a controlled VMware laboratory environment.

## Testing Conditions

- Testing was limited to the defined lab systems.
- No production systems were targeted.
- Exploitation was performed for validation and educational purposes.
- Evidence was collected during the assessment.
- Testing was performed using Kali Linux and authorized laboratory tools.

## Safety

Testing was restricted to the isolated lab environment to prevent
impact to external systems or networks.

## Evidence Handling

Screenshots and technical evidence were collected for documentation
and portfolio purposes.

Sensitive information such as passwords, session tokens, or private
credentials should be redacted before public GitHub publication.
