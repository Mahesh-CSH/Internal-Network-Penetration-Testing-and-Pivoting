# Conclusion

This project demonstrated a complete internal penetration-testing workflow in an isolated laboratory environment.

The assessment covered:

- Reconnaissance
- Network scanning
- Service enumeration
- Vulnerability assessment
- Exploitation
- Windows host compromise
- Network pivoting
- Internal network enumeration
- Evidence collection
- Security findings
- Remediation planning

The most significant technical demonstration was the use of a compromised Windows host as a pivot into an isolated internal network.

The project also demonstrated multiple vulnerable services and weak configurations on Metasploitable 2, including SMB, Java RMI, PostgreSQL, Tomcat, NFS, FTP, and legacy services.

A post-remediation retest was not performed.

This project is intended as a controlled cybersecurity laboratory demonstrating practical penetration-testing and internal-network assessment techniques.
