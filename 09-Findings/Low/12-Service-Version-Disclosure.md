# F-12 — Service Version Disclosure

## Severity
Low

## Affected Host
Metasploitable 2 — 10.10.10.130

## Description
Multiple services disclosed software names and versions during network enumeration.

## Evidence
- Full TCP service/version enumeration screenshot

## Impact
Service and version information can assist attackers in identifying potentially vulnerable software.

## Recommendation
- Minimize unnecessary service banners.
- Keep software patched and supported.
- Restrict access to unnecessary services.

## Status
Identified during the authorized laboratory assessment.
